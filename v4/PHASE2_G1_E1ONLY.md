# V4 G1 对照：只更新 E1

2026-10-22 用户授权与现有 E1+D1 实验并行，使用物理 GPU 1、3。新实验从同一原始 epoch-120 checkpoint 初始化 E1，保留原编码器结构。新 release、外部配置、运行目录独立；不修改或停止 GPU 0、2 上的旧实验。

## 唯一训练干预及其目的

旧实验同时优化 E1/D1，并要求 D1(G1) 恢复原 RGB。新实验只优化 E1，取消这条 RGB 重建损失。这样可以检验：去掉直接彩色重建约束后，相同监督能否进一步降低 G1 的关联能力。

最终设计是 G1 经受保护补偿恢复为近似 G0，再交给原 D0。直接从 G1 重建 RGB 并非这条最终路径的必要训练目标。新实验没有新增生成网络、输出头或分解网络；并未改写原基线论文复现。

## 配置和损失

`configs/phase2-g1-e1only.json` 单独保存配置，默认物理 GPU `[1,3]`、每卡 8 张、全局 batch16、512×512、FP32、30 轮。fit1433 张，每轮 90 次更新，共 2700 次。新的 TF1Adam 状态、恒定学习率 2e-6，与旧实验相同。GPU 数量和编号仍可在配置修改。

保留原作者的灰度外观、VGG、variation 和量化算术与权重；仅取消 RGB 重建项：

`L = 1e-7*VGG + 0.1*variation + lightness + 10*quantization + 0.1*L_med + 0.1*L_link`

医学和关联目标沿用 `PHASE2_G1.md` 的定义，包括医学 KD=0.5、关联温度=0.1、每轮刷新 fit G1 图库及排除源图。固定监督器参数，但保留对输入 G1 的梯度，经 E1 回传；量化监督分支仍为作者 8bit 前向、STE 近似反向，评估使用真实 PNG 读回。原连续灰度量化惩罚仍保留。

优化器仅包含 E1 参数。D1 副本不执行训练前向、不参与梯度、不更新，只随 checkpoint 保留兼容结构；E0/D0、VGG、医学模型和固定 ResNet 参数不更新。固定 D0 只在无梯度评价中直接读 G1；报告明确这只是直接读出诊断，并非后续完整授权恢复结果。新报告不再列 D1(G1)。

旧实验的关联损失是可微代理，变小不保证 Rank-1 下降。这次保持监督定义和权重一致，先隔离去掉恢复约束的影响；不同时换关联目标。VGG 等外观约束仍可能影响身份变化幅度。是否有效以实际 G1→RGB 和 G1→G1 Rank-1、AUROC、mAP 相对 G0/普通灰度/旧实验的变化判断。它们是同病灶跨照片的固定参照指标，不是独立身份隐私验收。

医学指标继续报告变化，不设通过阈值。30 轮结束停止，不进入加密、嵌入或提取训练，不自动选择“最佳”checkpoint。

## 运行

上传对应包到 `/data/zwc/zyh`，校验 SHA256 后解压，运行包内 `install-code.sh`。安装只写新的源码 release 和配置，不安装或升级依赖。

本包使用独立环境变量 `V4_G1_E1ONLY_CONFIG`，默认指向安装生成的 `configs/phase2-g1-e1only-<commit>.json`，不会读取旧的 `V4_G1_CONFIG`。包内 `phase2.sh preflight` 在新配置上执行完整 batch 的梯度检查和初始评估，但不更新参数。通过后，用输出报告路径运行 `phase2.sh train --preflight /绝对路径/report.json`。

输出目录前缀是 `runs/g1-e1only-preflight.*`、`runs/g1-e1only-train.*`。首次真实更新会输出：

`E1_UPDATE_VERIFIED encoder_changed=True decoder_changed=False`

各轮检查冻结参数不变，保留逐轮评价、训练指标和 checkpoint。预检不能证明关联下降；服务器训练和显存结果需实测。两卡各自是否有足够空闲显存由预检确认，不终止其他进程。
