# V4 G1 对照：只更新 E1，冻结 D1，保留全部损失

2026-10-22 用户授权与现有 E1+D1 实验并行，使用物理 GPU 1、3，随后明确“参数也是复制最初的E0；只有D1不更新，其他和上次一样”。本配置按这一最新要求执行。

## 初始化与唯一训练干预

从与旧实验完全相同的原始 epoch-120 checkpoint 复制 E0→E1、D0→D1。它是完成90＋30轮、10800步的基线，SHA256为 `5d7f8c2bed98356166bbecebbc87a7fb4324e75126a347e6173788a7fcbef387`。不读取上一组正在训练的 E1/D1，不随机重训生成器。E0/D0 原件冻结保留。

旧实验更新 E1和D1；本实验优化器只包含 E1，D1参数 requires_grad=False。D1仍参与前向，RGB重建损失保留，并通过固定D1向E1回传输入梯度。不能对D1前向使用no_grad或detach，不能把冻结D1写成取消恢复约束。D1副本与原D0数值保持一致，随checkpoint保存并检查不变。

助手此前准备的 a695298 版本额外取消了RGB恢复损失，不符合用户这一最新限定；该包未在服务器执行，保留为已取代的准备记录，不应启动。此次重新发布的版本恢复全部原损失。

## 与上一组相同的设置

独立 `configs/phase2-g1-e1only.json` 仅在schema、update_modules与gpu_ids上不同于 `phase2-g1.json`。默认物理GPU `[1,3]`、每卡8张、全局batch16、512×512、FP32、30轮、每轮90步、共2700步。数据顺序/随机种子、fit1433与val_tune169、新TF1Adam状态、恒定学习率2e-6保持相同。GPU编号与卡数可在配置修改。

完整损失：

`L = 3*MSE(D1(G1), X) + 1e-7*VGG + 0.1*variation + lightness + 10*quantization + 0.1*L_med + 0.1*L_link`

所有算术、权重、医学KD=0.5、检索温度=0.1与旧实验一致，定义见 `PHASE2_G1.md`。原连续灰度量化惩罚保留；新增监督分支仍是作者8bit前向/STE近似反向，评价用真实PNG读回。原编码器/解码器结构、作者损失文件和phase1代码不变。没有新增生成网络、输出头或分解网络。

PanDerm、8500主医学模型、公开ResNet、VGG仍冻结参数但保留图像输入梯度；7000仅评价。fit图库规则与每轮刷新不变，不使用验证/测试图库训练。医学只报告变化，不设通过阈值。

## 评价含义

同样报告 G1→RGB 与 G1→G1 Rank-1、AUROC、mAP，以及医学指标相对普通灰度/G0的变化。关联损失是训练代理，不保证Rank-1下降；固定D1可能继续限制E1的变化幅度，效果必须实测。保持全部损失的目的是隔离“D1能否随E1继续学习”的影响。

D1(G1)和D0(G1)均为直接读取诊断，本实验两者应一致。报告标明D1是D0冻结副本。这不替代未来Gpub提取/解密/补偿为近似G0，再经D0的完整授权恢复评价。本轮不修改或启动加密、嵌入、提取训练；30轮结束停止，不自动早停或选择最佳点。

## 运行和验证

新release、外部配置、运行目录独立，不修改/停止GPU0、2的旧实验；沿用已有ccrr_v2，不安装或升级环境。包使用独立环境变量 `V4_G1_E1ONLY_CONFIG`，不会误读旧 `V4_G1_CONFIG`。

安装后执行包内 `start-training.sh`：先独立预检，检查同一基线、所有损失、E1与监督输入梯度、D1零参数梯度/冻结状态，并做初始评价。预检零参数更新。只有对应配置和release的预检成功才自动后台训练。

输出前缀为 `runs/g1-e1only-preflight.*`、`runs/g1-e1only-train.*`。日志声明 `UPDATE_MODULES=['E1'] RGB_RECONSTRUCTION_LOSS=True DECODER_FROZEN=True`。首次真实更新输出 `E1_UPDATE_VERIFIED encoder_changed=True decoder_changed=False`，每轮继续检查所有冻结模型不变。若预检失败，保留日志且不启动新训练。

本地检查覆盖：同初始化的两方案首批全部loss数值及E1梯度一致；固定D1的重建损失单独可回传E1；只有E1优化更新；完整图/分步VJP及双进程/全局batch梯度等价。服务器容量、训练完成和关联效果另由真实回传确认。
